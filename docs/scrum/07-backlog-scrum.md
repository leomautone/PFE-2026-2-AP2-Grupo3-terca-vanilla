## 6. AP2

### 6.1 Escopo definido pelo professor

- Duas entregas: **site vanilla** (HTML, CSS e JS puro, no GitHub Pages) e **site React** (produto final da AP2, no Vercel).
- Sem cadastro, sem login e sem cards ou dados de treino de atletas.
- A única integração com back-end é o **agendamento de aula experimental**: no vanilla é só visual, no React é obrigatório.
- As telas 07 (perfil do aluno) e 08 (relatório para os pais) ficaram fora do escopo da AP2. Os itens PB01–PB05 e PB09–PB10 continuam no backlog como proposta para uma próxima etapa.

### 6.2 Como o grupo vai trabalhar

- Cada integrante fica responsável por uma página (ou por um conjunto de seções) do site vanilla.
- Cada um trabalha numa branch com o próprio nome e abre um Pull Request para a `main`.
- O Scrum Master revisa e faz o merge de todas as branches. O `css/base.css` (cores, fontes, header, footer e botões) é compartilhado e só ele edita.
- Cada integrante recebeu orientações individuais da sua parte (arquivos, conteúdo e passo a passo no Git), que ficaram no repositório vanilla durante a sprint.
